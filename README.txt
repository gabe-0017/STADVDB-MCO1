Local Run Steps
1. Download this repo
2. If you haven't yet: In MySQL, run the dataset dump (MCO1 - Dataset financedata.sql), then 'dw_schema.sql', then 'dw_etl.sql'
3. Inside the 'olap-dashboard' directory, modify the '.env.example' file (don't forget to rename the file to '.env' after)
4. Run 'npm install' and 'npm start' in cmd
5. Open "http://localhost:3000" in your browser

Note: I couldn't upload the 'MCO1 - Dataset financedata.sql' file in this repo because it was too big, I trust you know where to find it or already have it on you machine naman lol
